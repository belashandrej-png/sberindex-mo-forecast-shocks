# Подписи к фигурам (CAPTIONS)

Реестр всех графических артефактов проекта. Подпись сформулирована как **вывод**,
а не как описание: она отвечает на вопрос «что читатель должен понять из фигуры».
Подписи используются дословно в трёх местах: под фигурами в `report/report_ru.md`,
в титулах/подтитрах слайдов `report/presentation.pdf` и в README при необходимости.

## Правила оформления фигур

1. Подпись = вывод (одно предложение) + ключевые цифры в скобках.
2. Палитра семантическая (src/plot_style.py → PALETTE):
   синий #4C72B0 — факт; оранжевый #DD8452 — прогноз; серый #7F7F7F — бейзлайн;
   красный #C0392B — оффлайн-точки шоков; янтарный #E67E22 — онлайн-тревоги;
   зелёный #55A868 — новостные события.
3. Оси подписаны с единицами («Сумма трат, руб.», «Месяц»); сетка alpha=0.3;
   без верхней и правой рамок; DPI 150.
4. Каждая фигура воспроизводится ноутбуком, указанным в поле «Источник».

## stl_national.png
- **Подпись:** Национальный ряд = растущий тренд + стабильная сезонность + плоский

- **Содержание:** 4 панели STL-декомпозиции (multiplicative, period=12):

- **Ключевые цифры:** остаток в коридоре ±5% весь период; амплитуда сезонности 0.87–1.15.

## pres_architecture.png
- **Подпись:** Архитектура: прогнозный контур (признаки строго до t−1 → LightGBM, loss=MAE)
  плюс двухслойный контур шоков (онлайн-CUSUM + оффлайн Window/PELT, голосование ≥2).
- **Содержание:** блок-схема: данные → feature engine → LightGBM → прогноз;
  остатки → CUSUM; log-ряд → Window/PELT; новости → score; всё → слой шоков.
- **Ключевые цифры:** info set ≤ t−1; vote_threshold = 2.
- **Использование:** отчёт §2.1; README; слайд 4.
- **Источник:** блок фигур для презентации (Colab, Блок 8).
