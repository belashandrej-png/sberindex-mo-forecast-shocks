# Данные конкурса СберИндекс 2026

## Лицензионное ограничение

Данные предоставляются участникам **исключительно в рамках конкурса** по отдельной лицензии и **НЕ включены в этот репозиторий**.

**Что запрещено:**
- Коммитить parquet-файлы в git (защищено `.gitignore`)
- Использовать данные в коммерческих целях
- Передавать данные третьим лицам

Полный текст лицензии: `Данные_СберИндекс_лицензия.pdf` (в архиве конкурса).

## Где получить данные

1. Официальный портал: [sberindex.ru/ru](https://sberindex.ru/ru/) → раздел «Каталог данных»
2. Страница конкурса: [sber.ru/sberindex/konkurs_sberindex](https://sber.ru/sberindex/konkurs_sberindex)
3. Telegram-канал организаторов: [@sberindex_insight](https://t.me/+ZduE5IaMFApjMGVi) — там публикуются обновления данных и методические материалы

После скачивания архива распакуйте его в папку `data/hackathonlicence/`.

## Описание датасетов

### `consumption.parquet` — потребительские расходы

Безналичные транзакции клиентов Сбера, агрегированные по муниципальным образованиям и категориям трат.

| Столбец | Тип | Описание | Пример |
|---|---|---|---|
| `date` | string | Период в формате `'YYYY-MM'` | `'2023-01'` |
| `territory_id` | int16 | Уникальный идентификатор МО | `1`, `1429`, `3101` |
| `category` | string | Категория потребительских трат | `'Продовольствие'` |
| `value` | int32 | Сумма расходов, руб. | `7692` |

**Категории трат** (5 основных + агрегированная):
- `Продовольствие` — базовая категория (самый большой объём)
- `Маркетплейсы` — онлайн-потребление
- `Транспорт`, `Здоровье`, `Общественное питание`
- **`Все категории`** — агрегированная сумма

> **ВАЖНО для анализа:** таргетом прогнозирования должна быть **только строка `Все категории`**, а не сумма остальных пяти. Иначе возникает **двойной счёт** (сумма категорий ≠ строка "Все категории" из-за наличия скрытых мелких категорий).

**Период:** январь 2023 — декабрь 2024 (24 месяца)  
**Количество МО:** 2 571  
**Всего наблюдений:** 303 126 (2 571 МО × 24 мес × ~5 категорий)

### `connection.parquet` — связи между муниципалитетами

Пара расстояний между МО по дорожной сети (используется для расчёта пространственных признаков).

| Столбец | Тип | Описание |
|---|---|---|
| `territory_id_x` | int64 | ID первого МО |
| `territory_id_y` | int64 | ID второго МО |
| `distance` | float64 | Расстояние, км |
| `type` | string | Тип дороги (`highway`, etc.) |

**Всего связей:** 5 942 364 (почти полный граф)  
**Использование:** расчёт признака `min_dist` — минимального расстояния до ближайшего соседа (входит в топ-6 признаков модели).

### `market_access.parquet` — индекс доступности рынков

Характеристика каждого МО, отражающая его пространственное положение в экономической сети (теория рыночного потенциала Харриса, 1954).

| Столбец | Тип | Описание |
|---|---|---|
| `territory_id` | int32 | ID МО |
| `market_access` | float64 | Индекс доступности |

**Всего МО:** 2 571  
**Распределение:** бимодальное (два пика ~320 и ~620) — две группы территорий: периферия vs хорошо связанные города.

## Как данные используются в решении

| Датасет | Роль в модели |
|---|---|
| `consumption` | **Таргет** (строка «Все категории») + **доли категорий** как признаки (`share_food`, `share_mp`) |
| `connection` | Пространственный признак `min_dist` (экономическая география) |
| `market_access` | Статический признак `market_access` (рыночный потенциал Харриса) |
